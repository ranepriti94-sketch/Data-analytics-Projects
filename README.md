Coffee Shop Sales Analysis Dashboard (Excel)

📌 Project Overview
This is a personal data analytics project created in Microsoft Excel to analyze coffee shop sales data through an interactive dashboard.
The dashboard helps understand sales trends, product performance, and store-wise revenue insights.

🎯 Objectives

Analyze total coffee shop sales performance
Identify top-selling products
Compare sales across store locations
Track sales trends by day, month, and hour
Create an interactive dashboard using Excel

📊 Dashboard Features

Total Sales Revenue
Total Transactions
Average Sale per Transaction
Top 10 Selling Products
Sales by Product Category
Sales by Hour Analysis
Sales by Store Location
Day-wise and Month-wise Sales Trends
Interactive Slicers for filtering data

🛠 Tools Used

Microsoft Excel
Pivot Tables
Pivot Charts
Slicers
Data Cleaning
Dashboard Formatting

📈 Key Insights

Morning hours show highest sales activity
Coffee products generate maximum revenue
Some store locations perform better than others
Weekdays have stronger sales than weekends

🚀 Conclusion
This project shows how Excel can convert raw sales data into meaningful business insights using dashboards and visual analytics.
